# つくり手インサイト

仕様 ID: SPEC-CREATOR-INSIGHT

2026-11-13 指示: Slack / Discord のログ、ポートフォリオ、コードの書き方から、人生脚本・性格・プレイタイプを分析できるようにする。
人生脚本はアンケート式にする。まず LLM スキルとして導入し、集計はロジックで行う（ツールは必要になった時点で作る）。日本に特化する。

## 目的と境界

入口は `skills/creator-insight/SKILL.md`。本人の振り返りと、本人との対話の準備に使う。
コアの正本は LUDIARS/Discutere の `skills/creator-insight/`。このリポジトリ固有の事項は `skills/creator-insight/ADAPTER.md` に置く。

遊び手のプレイタイプは既存のペルソナ分析（persona v2）が正本であり、このスキルは結果を読むだけにする。
このスキルが足すのは、作り手の面、性格（行動スタイル）、人生脚本（アンケート）の3つ。

## 受入条件

- SPEC-CREATOR-INSIGHT-001: エージェントが読んで実行するスキルとして提供する。API、画面、migration を足さない。
- SPEC-CREATOR-INSIGHT-002: 本人の同意と目的の確認が無い場合は実行しない。採用・選考・評価・診断・監視には使わない。
- SPEC-CREATOR-INSIGHT-003: LLM が読むのは、特徴カード（仮名化済みの集計）と上限つきの引用だけ。生のログ・コードを文脈に入れない。アンケートの採点に LLM を使わない。
- SPEC-CREATOR-INSIGHT-004: 遊び手の15軸のスコアを作り直さない。ペルソナ分析の結果を第一の根拠として読む。
- SPEC-CREATOR-INSIGHT-005: 人生脚本アンケートの結果と、分類の `story_winner` / `story_banal` / `story_loser` を相互に写像しない。
- SPEC-CREATOR-INSIGHT-006: 分析結果を Voluptas の DB、データリポジトリ、エクスポート、ペルソナ分析の入力、Discutere へのブリッジに書かない。
- SPEC-CREATOR-INSIGHT-007: 出力は、根拠 ID と確度を付けた仮説とする。根拠不足は「データ不足」と書き、低い値と区別する。神経症傾向と、要配慮個人情報にあたる事項は出さない。
- SPEC-CREATOR-INSIGHT-008: 集計ツールは `player-profile-server/src/creatorInsight/` に必要になった時点で作り、架空データのテストを同じ場所に置く。仮名 ID は既存の pseudoId を使い、本人以外の本文を捨てる。
- SPEC-CREATOR-INSIGHT-009: 前提は日本語話者と日本の制作現場。比較は同じ集団の中の相対位置だけで行い、性別・年齢・出身などの属性を推定しない。

## データの扱い

| データ | 置き場所 | 保持 |
|---|---|---|
| エクスポートしたログ、中間ファイル | リポジトリの外の作業ディレクトリ | 分析の終了時に削除 |
| 特徴カード | 同上 | 本人への返却後に削除。本人が望む場合は本人に渡す |
| 対話用メモ | 本人に返す | 本人が管理する |

同意が撤回されたら、すべての作業ファイルをただちに削除する。
個人データの正本は Cernere であり、このスキルは氏名・メールアドレス・表示名を扱わない。
